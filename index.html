Выгодно ли предприятию уйти с розницы на оптовый рынок электроэнергии?

Потребитель на розничном рынке платит гарантирующему поставщику сбытовую надбавку. На ОРЭМ её нет — но появляются свои расходы: персонал, взносы, сопровождение. Модель сравнивает одно с другим и показывает, окупается ли выход.

02 · Аналитика

Темп роста сбытовых надбавок

Насколько изменились надбавки с 1 октября 2026 года по сравнению с первыми девятью месяцами — по регионам и в среднем по стране.

Темп роста = k₂ / k₁ − 1; по региону — среднее по его ГП. — регион используется в расчёте.

03 · Методика

Методика расчёта

Откуда берутся цифры на странице расчёта.

Формулы

Экономия по ГТПЭᵢ = k₁·ΣW(янв–сен) + k₂·ΣW(окт–дек)
Общая экономияЭ = Э₁ + Э₂ + … + Эₙ
ЗатратыЗ = Зштат + Зинфр + Зпроч
ЭффектЭф = Э − З
ЭффективностьE = Э / З · 100 %
Срок окупаемостимесяц, когда ΣЭ ≥ ΣЗ

k₁, k₂ — сбытовые надбавки ГП для класса мощности ГТП в первом и втором периоде, руб./кВт·ч; W — потребление за месяц, кВт·ч. Зштат = 12·Σ(оклад·численность) — штат специалистов по работе на ОРЭМ; Зинфр — затраты на инфраструктуру ОРЭМ (ставка × количество); Зпроч = 12·прочие расходы в месяц.

Вывод о целесообразности

  • Целесообразен — эффект положительный, эффективность не ниже 120 %.
  • На грани окупаемости — эффект положительный, но запас меньше 20 %.
  • Нецелесообразен — затраты превышают экономию.

Допущение: разовые платежи учитываются в начале года, ежемесячные расходы распределяются равномерно.

Источник данных

  1. Сайт органа регулирования тарифов субъекта РФ (например, Комитета по тарифам Санкт-Петербурга), раздел «Тарифы».
  2. Тарифы на электрическую энергию за 2026 год → сбытовые надбавки гарантирующих поставщиков.
  3. Распоряжение (приказ) об установлении сбытовых надбавок и приложение к нему.
  4. Надбавки для прочих потребителей, дифференцированные по максимальной мощности ЭПУ, заносятся в сводную таблицу.
